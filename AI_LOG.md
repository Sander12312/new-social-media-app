# AI Usage Log

**Tools Used**

ChatGPT (OpenAI)

During this assignment, I used ChatGPT as a learning assistant while developing a social media application using Tailwind CSS.

I used ChatGPT to better understand the assignment requirements, explore design suggestions, configure Tailwind CSS, and troubleshoot issues.

ChatGPT also provided HTML, CSS, and JavaScript code examples and implementation suggestions, including larger parts of the page structures. I reviewed and adapted these suggestions, tested the results in the browser, and worked on understanding how the code functioned.

- Exploring HTML structures and design solutions for the authentication, feed, and profile pages.
- Receiving code examples and implementation suggestions for HTML, CSS, and basic JavaScript interactions.
- Learning how to create reusable CSS components and reduce repetitive code.
- Troubleshooting styling issues encountered during development.
- Reviewing the project against the assignment requirements.

Using ChatGPT helped me become more familiar with Tailwind CSS and how reusable components can make a project easier to maintain.
